# Market index and listing

This repository publishes a format-1 plugin market index:

- `https://cdn.jsdelivr.net/gh/Kattentions/dsh-mobile-bridge@main/index.json`
- fallback: `https://raw.githubusercontent.com/Kattentions/dsh-mobile-bridge/main/index.json`

Add it under **Plugins → Discover → Index sources** in DSH 0.2.1+.

For the community list, an entry file for
[awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin)
is prepared in `docs/awesome-entry.yml`; it can be submitted once the repository
is at least one day old (their rule) with the `dsh-plugin` topic set.
